# ChatGPT GD Pet

A Geometry Dash-inspired animated pet for ChatGPT.

![Add to ChatGPT](https://img.shields.io/badge/ChatGPT-Custom%20Pet-10a37f?style=flat-square)
![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Status](https://img.shields.io/badge/status-released-brightgreen)

## Installation

[![Add to ChatGPT](https://img.shields.io/badge/Add%20to-ChatGPT-10a37f?style=for-the-badge&logo=openai&logoColor=white)](https://chatgpt.com/s/sharepet_6afef4bfeccc8191a698c14b18a1906e)

1. Click **Add to ChatGPT**.
2. Open the pet share page.
3. Follow the on-screen instructions.
4. Enjoy your Geometry Dash pet!

## Features

- Classic yellow and cyan Geometry Dash cube.
- Idle animations.
- Animated facial expressions.
- Waving and jumping animations.
- Custom spritesheet.
- ChatGPT pet sharing support.
